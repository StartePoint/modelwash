# ModelWash 详细设计书

| 项 | 内容 |
|----|------|
| 版本 | 0.1 |

本文给出 **核心类型、接口、清洗参数、错误码与关键算法契约**。命名可在实现时微调，但职责边界应保持。

---

## 1. 命名空间与编码约定

- 根命名空间：`modelwash::`
- 头文件：`modelwash/...hpp`
- 错误：返回 `Result<T, Error>` 或 `std::expected`（实现时统一一种）；面向用户的 `messageZh` 在 presentation 层组装或 core 提供键。
- 字符串路径：`std::filesystem::path`；QML 边界用 `QString`。

## 2. Document 模型

### 2.1 类型

```text
Document
  id: Uuid
  nodes: vector<SceneNode>
  selection: set<NodeId>
  meta: DocumentMeta          // 源路径、导入警告、动画标志

SceneNode
  id: NodeId
  name: string
  visible: bool
  localTransform: TRS         // T vec3, R quat, S vec3
  mesh: optional<MeshData>    // 叶子可持网格；空节点允许
  materialId: optional<MaterialId>
  children: vector<NodeId>    // 0.1 可先扁平列表，保留字段

MeshData
  positions: float3[]
  normals: float3[]           // 可空，导入后可重算
  uvs: float2[]               // 可空
  indices: uint32[]           // 三角
  flags: MeshFlags            // Skinned, HasMorph, ...

Material
  id, name
  baseColorFactor: rgba
  metallic, roughness
  baseColorTexture: optional<TextureId>
  // 0.1 足够；扩展贴图槽 0.4

Texture
  id, name, width, height, channels
  pixels: blob                // 或磁盘缓存键

DocumentMeta
  sourcePath
  warnings: vector<WarningCode>
  hasAnimation: bool
  hasSkinning: bool
  hasMorph: bool
  triangleCount: uint64
  approxTextureBytes: uint64
```

### 2.2 不变量

- 所有编辑通过 Command 修改 Document（直接改仅限加载/内部 rebuild）。
- `triangleCount` 等统计在网格变更后失效并重算。
- Bake-merge（0.3）产出新 MeshData，变换烘进顶点。

## 3. Command 栈

```text
ICommand
  + nameZh(): string
  + execute(Document&): void
  + undo(Document&): void

CommandStack
  + push(unique_ptr<ICommand>)   // execute + 入栈，清 redo
  + undo()
  + redo()
  + canUndo/canRedo
  + clear()
```

### 3.1 0.1 命令

| Command | 作用 |
|---------|------|
| `ReplaceDocumentCommand` | 打开新文件替换场景（或 Clear+Add） |
| `AddNodesCommand` | 追加导入 |
| `DeleteNodesCommand` | 删除选中 |
| `SetVisibilityCommand` | 显示隐藏 |
| `ApplyWashResultCommand` | 将清洗结果写回 Document |

### 3.2 后续命令

| 切片 | Command |
|------|---------|
| 0.2 | `SculptStrokeCommand`, `GlobalSmoothCommand` |
| 0.3 | `TransformCommand`, `AlignCommand`, `GroundCommand`, `SurfaceSnapCommand`, `BakeMergeCommand` |
| 0.4 | `ApplyBeautyPresetCommand`, `SetMaterialPropsCommand`, `SetLightingPresetCommand`（若灯光存 Document；也可仅 Session 态） |

**灯光/背景**：可放在 `PresentSessionState`（不进撤销）或 Document；推荐 **Session 态不撤销**，材质美化进撤销。

## 4. FormatAdapter（IO）

```text
struct ImportRequest { path; options; }

struct ImportResult {
  vector<SceneNode> roots; // 或整棵树
  vector<Material> materials;
  vector<Texture> textures;
  DocumentMeta meta;
}

class IFormatAdapter {
  virtual bool canOpen(path) const = 0;
  virtual ImportResult import(ImportRequest) = 0;
  virtual string formatId() const = 0; // "assimp", "glb-native", ...
}

class FormatRegistry {
  + registerAdapter(...)
  + open(path) -> ImportResult   // 选第一个 canOpen
}
```

### 4.1 AssimpImportAdapter

- 支持扩展名：`.glb`, `.gltf`, `.obj`, …（以 Assimp 编译选项为准）
- 转入中间 `MeshData`（三角化、合并需记录警告）
- 设置 `hasSkinning/hasMorph/hasAnimation` 供 Wash 使用

### 4.2 GlbExporter（产品导出，非 Assimp）

```text
struct ExportRequest {
  const Document& doc;
  path output;
  WashSettings applied;      // 已应用或导出时再应用
  bool embedTextures;
}

class GlbExporter {
  + export(ExportRequest) -> void
}
```

写出要求：

- 合法 GLB2
- 按设置写入 Draco 或 meshopt 扩展（若启用）
- 失败不截断覆盖：先写临时文件再 rename

## 5. Wash 管线详细设计

### 5.1 设置结构

```text
enum class WashTarget { Web, Game, Custom }

struct WashSettings {
  WashTarget target;
  // 几何
  bool simplifyGeometry;          // 受 StaticWashOnly 约束
  float simplifyRatio;            // 0~1 保留比，或目标三角数
  optional<uint32> targetTriangles;
  // 贴图
  uint32 maxTextureEdge;          // 2048/1024/512
  enum class TexCodec { Keep, Jpeg, WebP } texCodec;
  int texQuality;                 // 1~100
  // 清理
  bool pruneUnused;
  bool weldVertices;              // 谨慎默认
  bool dedupeAccessors;
  // 压缩
  enum class GeomCompression { None, Draco, Meshopt } geomCompression;
  int compressionLevel;
}
```

### 5.2 目标预设（初始值，实现可微调）

| 参数 | 网页 Web | 游戏 Game |
|------|----------|-----------|
| `simplifyRatio` | ~0.5（较强） | ~0.7（较保守） |
| `maxTextureEdge` | 1024 | 2048 |
| `texCodec` | WebP 或 Jpeg | Keep 或 Jpeg |
| `geomCompression` | Meshopt 优先（或 Draco，视文档说明） | Draco 或 None（兼容优先时可 None+说明） |
| `weldVertices` | true（无 skin 时） | false 默认 |
| StaticWashOnly | 始终生效 | 始终生效 |

> 网页 vs 游戏的压缩族以「主路径可加载」为准；在关于/高级里写清推荐运行时。若实测某压缩在目标引擎不友好，只改预设表，不改架构。

### 5.3 流水线步骤

```text
WashPipeline::run(inputDoc, settings) -> WashResult
  1. Clone document (预览/应用共用)
  2. Analyze flags → 填写 skippedMeshes
  3. pruneUnused (可选)
  4. For each eligible mesh: simplify (meshoptimizer)
  5. Resize/recompress textures
  6. Weld/dedupe (可选)
  7. Stats: triangles, textureBytes, estimateFileBytes
  8. Return { document, stats, warnings }
```

`estimateFileBytes`：可对临时 GLB 跑一遍导出到内存/临时文件计量（0.1 推荐，数字才可信）。

### 5.4 PersonaProfile 对默认的影响

| 人设 | 打开清洗面板时 |
|------|----------------|
| AssetShipper | 默认目标=游戏或上次；强调「导出」 |
| AICleanup | 默认目标=网页或更强减面；Toast 提示可去「修一修」（0.2 起） |

## 6. TouchUp（0.2）

### 6.1 笔刷

```text
enum class BrushKind { Smooth, Inflate, Flatten }

struct BrushParams {
  BrushKind kind;
  float radiusWorld;
  float strength;      // 0~1
}

class TouchUpSculptor {
  // hit: 射线与网格交点 + 法线
  + applyStroke(Document&, NodeId, strokeSamples[], BrushParams) -> 生成 Command 数据
  + globalSmooth(Document&, NodeId, iterations=1)
}
```

契约：

- 只改 `positions`（必要时重算法线）
- 一笔 → 一条 `SculptStrokeCommand`（存 before/after 顶点差或完整副本；大网格用差量）
- 交互软预算：>150k 三角警告

## 7. Assemble（0.3）

| 操作 | 行为 |
|------|------|
| Ground | 选中物体世界 AABB 底面对齐 y=0（或场景地面） |
| Center | 选中移到原点或父空间中心 |
| AlignBBox | 相对最后选中/活动对象对齐指定轴 |
| SurfaceSnap | 从物体原点或枢轴向下/向相机射线，命中其它网格表面则平移贴合；失败则提示 |
| BakeMerge | 多选烘变换，合并网格（材质：同材合并或分 primitive），导出或写回 |

**无布尔**：不提供并集差集 API。

## 9. Presentation 绑定（QML）

```text
DocumentSession : QObject
  Q_PROPERTY documentStats
  Q_PROPERTY mode            // wash/touchup/...
  Q_PROPERTY canUndo/canRedo
  Q_PROPERTY washPreviewStats
  slots:
    openFile(QUrl)
    exportGlb(QUrl)
    setWashTarget(...)
    previewWash()
    applyWash()
    undo()/redo()
  signals:
    errorOccurred(QString messageZh)
    progress(double, QString)
```

长任务：`QtConcurrent` 或 worker 线程跑 Wash；结果回主线程 `ApplyWashResultCommand`。Document 线程规则：**仅主线程写 Document**，或明确加锁（推荐主线程写）。

## 11. 错误码（core）

| Code | 含义 | 用户侧 |
|------|------|--------|
| `IoNotSupported` | 扩展名无适配器 | 请转 GLB |
| `IoAssimpFailed` | 读入失败 | 读失败+原因 |
| `IoExportFailed` | 写出失败 | 未覆盖 |
| `WashSkippedSkinned` | 警告非致命 | 已跳过减面 |
| `WashCancelled` | 用户取消 | 已取消 |
| `PickMissed` | 吸附未命中 | 换角度再试 |
