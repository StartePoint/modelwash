# ADR-019: Brand and mode copy (Chinese-first)

## Status
Accepted

## Date
2026-09-29

## Context
Consumer UX needs stable names aligned with the glossary.

## Decision
- Product: **ModelWash / 洗模型**
- Primary modes (UI): **清洗** (Wash), **修一修** (TouchUp), **拼一拼** (Assemble), **摆好看** (Present)
- Keep jargon out of primary chrome; advanced panels may show technical terms

## Consequences
- CONTEXT.md and UI strings stay in sync with these labels
