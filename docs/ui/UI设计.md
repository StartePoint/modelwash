| 项 | 内容 |
|----|------|
| 版本 | 0.1（对齐 ReleaseTrain，后续切片增量） |
| 状态 | 已与 `docs/CONSENSUS.md` / ADR 对齐 |
| 产品名 | ModelWash / 洗模型 |
| 原则 | 同时只开一种编辑模式；预设优先；专业参数进「高级」 |

相关：ADR-005、019、011、012、014、018。

---

## 1. 设计目标

- **像美图**：大按钮、少术语、一条主路径完成「打开 → 清洗 → 导出」。
- **不像 Blender**：无节点、无深树、无海量工具架。
- **双人设**：首次选择影响默认文案与推荐清洗档，不锁死功能。

---

## 2. 信息架构

```text
启动
 ├─ 首次？ → 人设选择（PersonaProfile）
 └─ 主壳 MainShell
      ├─ 顶栏 TopBar
      ├─ 左栏 ObjectRail（物体卡片列表）
      ├─ 中区 Viewport（Qt Quick 3D）
      ├─ 右栏 ModePanel（随模式切换）
      └─ 底栏 StatusBar（面数 / 警告 / 进度）
```

**全局模式（互斥）**

|---------|------|------|----------|
| `wash` | 清洗 | 0.1 | 目标预设、对比、导出 |
| `touchup` | 修一修 | 0.2 | 笔刷、半径/强度、一键光滑 |

## 3. 关键流程

### 3.1 首次人设选择

全屏居中两张大卡片（非设置页堆砌）：

| 卡片 | 标题 | 副文案 | 默认后果 |
|------|------|--------|----------|
| AssetShipper | 我要交付资源 | 网页 / 小游戏用，优先体积与兼容 | 推荐「网页」或「游戏」清洗；弱化修一修引导 |
| AICleanup | 我要修 AI 出的模 | 先抹平再瘦身 | 打开后提示可「修一修」；清洗默认略保守 |

底部：「可在设置里随时更改」。选择后写入本地 QSettings，进入空主壳或打开文件对话框。

### 3.2 0.1 主路径（必须顺）

1. 拖入 /「打开」GLB（或 OBJ 尽力）  
2. 视口自动框选居中  
3. 若 >15 万三角 → 底栏黄条；>50 万 → 橙条并建议先清洗  
4. 右栏选 **网页** 或 **游戏** →「预览效果」（显示前面数/约体积）→「导出 GLB」  
5. 若含 skin/morph/动画 → 对话框：几何减面将跳过，仍可压缩贴图/打包  

### 3.3 错误文案（固定语气）

| 场景 | 文案方向 |
|------|----------|
| 不支持的格式 | 「暂时打不开这种格式，请先转成 GLB 再试。」 |
| Assimp 失败 | 「模型读失败：…（简短原因）。可换 GLB 再试。」 |
| 导出失败 | 「导出没成功，文件未被覆盖。请换路径或关闭占用后重试。」 |
| 清洗跳过蒙皮网格 | 「检测到骨骼/变形动画，已跳过减面，避免把动画搞坏。」 |

## 4. 布局线框

### 4.1 主壳（桌面，建议默认 1440×900）

```text
┌──────────────────────────────────────────────────────────────┐
│ [打开][导出]  [撤销][重做]     洗模型      [清洗|修一修|…] [⚙][?] │
├────────┬───────────────────────────────────────┬─────────────┤
│ 物体   │                                       │  模式面板   │
│ ┌────┐ │              View3D                   │  (随模式)   │
│ │卡片│ │         轨道旋转 / 缩放                │             │
│ └────┘ │                                       │             │
│  + 导入│                                       │             │
├────────┴───────────────────────────────────────┴─────────────┤
│ 面数 128k │ 贴图 ~12MB │ 就绪 / 清洗中…              本地处理 │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 清洗面板（0.1）

```text
清洗
○ 网页    ○ 游戏    ○ 自定义▾

[ 清洗前 ]  面数 / 约体积
[ 清洗后 ]  面数 / 约体积   （预览后填）

[ 预览清洗效果 ]
[ 导出 GLB ]

高级 ▾
  贴图最长边  2K|1K|512
  几何压缩    Draco|Meshopt|无
  减面强度    滑条或轻/中/强
```

### 4.3 修一修面板（0.2）

```text
修一修
笔刷  (抹平) (鼓一点) (压平)
半径  ────●────
强度  ────●────
[ 整体光滑一下 ]
提示：大模型请先清洗；可撤销
```

### 4.4 拼一拼面板（0.3）

```text

[ 贴地 ] [ 居中 ] [ 对齐包围盒 ▾ ]
[ 表面吸附：开/关 ]
[ 合成一个 GLB 导出 ]

```

### 4.5 摆好看面板（0.4）

```text

灯光  影棚|户外|柔光|白底
背景  纯色|渐变|HDRI 缩略图…
美化  磨砂|金属|陶瓷|塑料
材质  颜色 / 金属度 / 粗糙度 / 换贴图
[ 截图 ] □ 透明底
```

## 5. 组件与交互规范

| 元素 | 规范 |
|------|------|
| 模式切换 | 顶栏分段控件；切换不丢 Document；未解锁模式 disabled |
| 物体卡片 | 缩略/名称/可见眼睛/选中高亮；多选仅拼一拼需要时启用 |
| 视口 | 左键轨道（或中键），滚轮缩放；修一修时左键改为笔刷，轨道改右键/Alt |
| 进度 | 清洗/导出用模态或底栏进度，可取消（取消不写半截文件） |
| 设置 | 人设、更新检查开关、语言（默认中文）、恢复默认灯光 |

**动效（克制）**：模式面板淡入 150–200ms；卡片选中轻微缩放。不做粒子炫光。

**色彩**：独立于「AI 默认紫」；建议中性深底 + 一枚品牌强调色（实现时在 QML 主题里定 CSS/Token，本稿不锁死色值）。

## 7. 无障碍与键鼠（最低）

- 顶栏按钮有 Tooltip  
- 危险覆盖导出：确认框  
- 快捷键（1.0 可补全）：`Ctrl+O` 打开，`Ctrl+S`/`Ctrl+E` 导出，`Ctrl+Z`/`Ctrl+Y` 撤销重做
